# Лабораторная работа 1
Скрипт определяет операционную систему, на которой он запущен, и собирает информацию о компьютере.
Программа работает в Windows, Linux и macOS. Используются только стандартные модули Python. Системные утилиты ОС не вызываются.
Собранная информация о системе сохраняется в файл system_info.json.

# Программа собирает следующие данные:

- название операционной системы;
- версию операционной системы;
- архитектуру системы;
- имя компьютера;
- информацию о процессоре;
- количество логических процессоров;
- общий объём системного диска;
- объём свободного места на системном диске


# В программе используются стандартные модули Python:

-platform - получение информации об операционной системе, архитектуре и процессоре;
-socket - получение имени компьютера;
-os - получение количества логических процессоров;
-shutil - получение информации о диске;
-json - сохранение собранных данных в файл формата JSON.
